# BNAP

BNAP is an open protocol for paying for and authorizing machine-to-machine
requests over HTTP and MCP. A server states what a request costs and which
proofs it accepts; a client attaches a payment or an authorization proof (for
example ecash notes, L402 or MPP); the server verifies that proof before it
serves the request.

> [!WARNING]
> BNAP is pre-alpha. Draft-00 is the current text, and anything in it can
> change without notice.

## How to read this book

Every chapter under *Specification*, *Schemes* and *History* is a file from
the `spec/` directory of the repository, included unchanged when the book is
built. The book adds no protocol text of its own, so it cannot drift from the
repository.

- **[Socket draft-00](spec/socket-draft-00.md)** is the normative text: byte
  layouts, algorithms and test vectors that every deployment shares.
- **[Design overview v0.5](spec/overview-v0.5.md)** explains the design. Where
  it and draft-00 differ, draft-00 wins.
- **[Errata](spec/ERRATA.md)** lists the known differences between draft-00,
  the reference code and vectors, and the overview, and
  **[Provisional decisions](spec/DECISIONS.md)** records how the open ones are
  resolved for now.
- **[bnap:notes](spec/schemes/bnap-notes.md)** is the default credential
  scheme, still in its v0.4 form.
- The **History** chapters are superseded versions, kept unchanged.

The [specification index](spec/README.md) explains where each file came from
and how to read references to "tabs" in the text.

## Test vectors and reference code

The test vectors live in
[`vectors/vectors.json`](https://github.com/bnap-protocol/bnap/blob/main/vectors/vectors.json).
They are generated by the standard-library Python reference encoder,
[`reference/python/bnap_ref.py`](https://github.com/bnap-protocol/bnap/blob/main/reference/python/bnap_ref.py),
and CI checks on every change that the encoder still reproduces the file byte
for byte.
