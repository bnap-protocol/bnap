# BNAP

BNAP is an open protocol for paying for and authorizing machine-to-machine
requests over HTTP and MCP. It describes how a server states what a request
costs and which proofs it accepts, how a client attaches payment or an
authorization proof to the request (for example ecash notes, L402 or MPP), and
how the server verifies that proof before it serves the request. This
repository holds the specification text, reference material and the test
vectors that implementations are checked against.

**Status:** pre-alpha, draft-00. Anything here can change without notice.

[![CI](https://github.com/bnap-protocol/bnap/actions/workflows/ci.yml/badge.svg?branch=develop)](https://github.com/bnap-protocol/bnap/actions/workflows/ci.yml)

## Reading the specification

Start with [`spec/README.md`](spec/README.md), which lists the files and the
precedence rule: [`spec/socket-draft-00.md`](spec/socket-draft-00.md) is
normative and wins over the v0.5 overview wherever the two differ.

The same files are rendered as a book. Every push to `main` publishes it to
https://bnap-protocol.github.io/bnap/ (once GitHub Pages is switched on for
the repository). The book only includes the files in `spec/`, so it never
holds a second copy of the text. Build it locally with
[mdBook](https://rust-lang.github.io/mdBook/) 0.5:

```sh
mdbook build book    # or: mdbook serve book
```

## Test vectors

[`vectors/vectors.json`](vectors/vectors.json) is generated by the
standard-library Python reference encoder. CI checks that it is reproduced
byte for byte:

```sh
python3 -I reference/python/bnap_ref.py > vectors/vectors.json
```
