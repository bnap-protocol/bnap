# Errata: draft-00, reference code and vectors, v0.5 overview

Spec text licensed CC-BY-4.0, (c) BNAP contributors. Compiled 2026-10-13.

This table lists every inconsistency found between three sources:

- **draft-00**: [socket-draft-00.md](socket-draft-00.md), doc rev 39. Normative.
- **ref / vectors**: [bnap_ref.py](../reference/python/bnap_ref.py) (sha256 `aaede669…bbc47d1e`) and [vectors.json](../vectors/vectors.json) (sha256 `f21ff83a…4094ae14`).
- **overview**: [overview-v0.5.md](overview-v0.5.md), v0.5.1, doc rev 33.

Rows 30 and 31 are internal to draft-00 or concern the bnap:notes tab; rows 32 to 34 come from findings outside these sources, supplied with the export task; row 35 comes from the end-to-end conformance run against a real gate.

**Rule.** Draft-00 wins unless a vector proves otherwise. Where draft-00 is silent, the row says so, and adding a normative rule is marked as an owner decision.

**Draft-00 against the vectors.** No row: they agree. All 11 full hex values and all 9 shortened values in draft-00 section 14, and both hex blocks (the 305-byte offer and the Response), match `vectors.json`. The base64url prefixes in the 10.3 example decode to the start of the vector offer, credential and Response, and `BNAP-Error: AAEBAgEQ` decodes to code 16. The 10.3 arithmetic holds (1,680 sat ceiling, 425 sat before and 340 sat after the discount). The BIP-340 code reproduces official vector 0, and regenerating the vectors gives identical bytes.
